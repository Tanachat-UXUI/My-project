Token to CSS

แปลงไฟล์ JSON จาก Tokens Studio for Figma เป็น CSS variables สำหรับทีม dev

1อัปโหลดไฟล์ token แยกตามชั้น

เลือกโฟลเดอร์เดียว ระบบแยกเข้าช่อง Primitive / Semantic / Component ตามชื่อโฟลเดอร์ย่อยให้อัตโนมัติ หรือลากโฟลเดอร์มาวางที่นี่
หรืออัปโหลดแยกทีละช่อง

2ตั้งค่าการแปลง

กำลังแสดงข้อมูลตัวอย่าง ไม่ใช่ไฟล์ของทีม (มีข้อผิดพลาดที่ตั้งใจใส่ไว้ 2 จุดเพื่อให้เห็นการแจ้งเตือน)
ยังไม่ได้อัปโหลดไฟล์

อัปโหลดไฟล์ token ที่ช่อง Primitive, Semantic และ Component ทางซ้าย ผลตรวจสอบและ CSS จะแสดงที่นี่

ตัวอย่างตัวแปร CSSค่าใน CSSค่าต้นฉบับจาก Figmaชุดสถานะ
